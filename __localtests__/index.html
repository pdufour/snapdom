npm scripts

  • npm run debug:fo-fix-lab — compile + fo-fix-lab.mjs --serve (static server; does not open Chrome)
  • npm run debug:fo-svg-sandbox — compile + headed Chrome on FO SVG sandbox
  • npm run debug:fo-svg-sandbox:probe-translate-z — sandbox with --probe-translate-z
  • npm run compile — build dist/ (required for harness boot)

CLI (headed Chrome / matrix)

Playwright matrix and calibrate runs need --open-browser (or SNAPDOM_FO_LAB_OPEN_BROWSER=1).

  • node __localtests__/local-http-server.mjs — static server only (prints this index first)
  • node __localtests__/fo-fix-lab.mjs --serve — same (via fo-fix-lab entry)
  • node __localtests__/fo-fix-lab.mjs --matrix --open-browser — mini fixture matrix
  • node __localtests__/fo-fix-lab.mjs --matrix --open-browser --limit 50 — smoke
  • node __localtests__/fo-fix-lab.mjs --calibrate --open-browser --limit 15 — checkout landmarks
  • node __localtests__/fo-fix-lab.mjs --recipe product-baseline --open-browser — single recipe
